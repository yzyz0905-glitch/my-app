# Count Masters (群衆クラッシュ＆棒人間ランニングゲーム)

HTML5 / CSS3 / JavaScript (Three.js) で作られた、3Dハイパーカジュアル・ランナーゲームのMVPです。
ゲートをくぐって棒人間の軍隊を増やし、敵の軍団やトラップを突破してボスの砦を打ち破りましょう！

## 🎮 ゲームの特徴
- **3Dグラフィックス & ランニングアニメーション**: Three.jsによる手足を振って走る生き生きとした棒人間軍団
- **群衆フォーメーション（スォームシステム）**: 人数に合わせて自然な密集隊列（フェルマーの螺旋）を組んで滑らかに追従
- **計算ゲート**: `+10`, `x2`, `-5`, `÷2` などのゲートを通過して味方を大量増殖
- **トラップ & 敵軍とのクラッシュ**:
  - 回転トゲバーや動く障害物を回避
  - 赤い敵集団と1対1で激突・相殺する爽快なクラッシュ演出
- **ボスクラッシュ & マルチプライヤーステアーズ**:
  - ゴールでは巨大な赤ボスと味方軍団が一斉ダイブで激闘
  - ボス撃破後は倍率階段（x1.2〜x10.0）を駆け上がりハイスコアを獲得！
- **サウンド演出**: Web Audio API によるプロシージャル効果音（BGMリズム、チャイム、ポップ音、クラッシュ音、歓声）
- **スキンカスタマイズ**: ブルー、グリーン、オレンジ、パープルのお好みの色に変更可能

## 🕹️ 操作方法
- **スマホ / タブレット**: 画面を指で左右にスワイプ
- **PC**: マウスドラッグ または `←` / `→` キー（`A` / `D` キー）
